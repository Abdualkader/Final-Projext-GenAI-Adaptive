# GenAI Adaptive Learning Assistant for Children with Autism Spectrum Disorder (ASD)

A graduation project developing a Flutter-based educational assistant for children with ASD, featuring multi-sensory vocabulary learning, adaptive difficulty, AI-assisted exercises, and a dedicated parent/educator dashboard.

## 🚀 Quick Summary

* **Frontend:** Flutter & Dart
* **Backend:** Firebase (Authentication, Cloud Firestore, Cloud Storage, Cloud Functions)
* **AI:** Generative AI API accessed securely via Cloud Functions
* **Languages:** Arabic (RTL) & English (LTR)
* **Categories:** Letters, Numbers, Colors, Animals
* **Target Audience:** Children with ASD (ages 4–10), Parents, and Educators
